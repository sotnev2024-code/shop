# Обзор структуры проекта Shop

Этот проект представляет собой полнофункциональный интернет-магазин, реализованный в виде Telegram Mini App.

## Основные компоненты

### 1. Backend (`/backend`)
Построен на **FastAPI** с использованием асинхронности.
- **`app/`**: Основной код приложения.
    - **`api/v1/`**: Эндпоинты API для работы с товарами, корзиной, заказами, пользователями и админ-панелью.
    - **`bot/`**: Интеграция с Telegram Bot API (aiogram). Обработка команд, уведомлений и запуск WebApp.
    - **`db/`**: Слой работы с базой данных (SQLAlchemy). Модели данных находятся в `models/`.
    - **`schemas/`**: Pydantic-схемы для валидации данных и сериализации API.
    - **`services/`**: Бизнес-логика (оформление заказов, интеграция с МойСклад/1С, рассылки, платежи).
    - **`config.py`**: Глобальные настройки приложения (через pydantic-settings).
    - **`main.py`**: Точка входа FastAPI, настройка middleware, фоновых задач (APScheduler) и роутинга.
- **`alembic/`**: Миграции базы данных для управления схемой таблиц.
- **`requirements.txt`**: Список Python-зависимостей.

### 2. Frontend (`/frontend`)
Современное SPA на **React** + **Vite** + **TypeScript**.
- **`src/`**: Исходный код фронтенда.
    - **`admin/`**: Компоненты и страницы панели управления для администраторов.
    - **`api/`**: Клиент для взаимодействия с бэкендом (axios/fetch).
    - **`components/`**: Переиспользуемые UI-компоненты (кнопки, карточки, навигация).
    - **`hooks/`**: Кастомные React-хуки.
    - **`pages/`**: Основные страницы приложения (Каталог, Продукт, Корзина, Профиль и т.д.).
    - **`store/`**: Управление состоянием (Zustand) — корзина, избранное, настройки.
    - **`types/`**: TypeScript интерфейсы и типы.
    - **`App.tsx`**: Корневой компонент, настройка роутинга и инициализация Telegram WebApp.
- **`tailwind.config.js`**: Конфигурация стилей Tailwind CSS.

### 3. Корневая директория
- **`README.md`**: Общая документация проекта.
- **`start.ps1`**: PowerShell-скрипт для автоматического запуска локальной среды разработки (установка зависимостей, создание venv, запуск backend и frontend).
- **`deploy.sh` / `update.sh`**: Скрипты для развертывания и обновления проекта на сервере.
- **`nginx.conf`**: Пример конфигурации Nginx для продакшена.
- **`.env.example`**: Шаблон переменных окружения (токены бота, ключи API, настройки БД).

## Технологический стек
- **Backend**: Python 3.10+, FastAPI, SQLAlchemy, Alembic, Aiogram, APScheduler.
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Zustand, React Router.
- **Database**: SQLite (для разработки), PostgreSQL (рекомендуется для продакшена).
- **Deployment**: Docker (опционально), Nginx, Bash-скрипты.
